# Reminder Bot  


Система напоминаний с отправкой уведомлений через Telegram. Проект состоит из API‑сервиса, телеграм-бота и фонового воркера, взаимодействующих через Redis.


## Описание


Проект реализует сервис напоминаний:
* Пользователь создаёт напоминание через бота, который обращается к апи.
* Система сохраняет данные в БД и ставит задачу в очередь.
* Воркер обрабатывает задачу в указанное время и отправляет уведомление в Telegram.
* После отправки статус напоминания обновляется.


**Ключевые технологии:**
* Python 3.11+
* FastAPI (API‑сервис)
* Celery (асинхронная обработка задач)
* Redis (очередь задач и брокер)
* aiogram (интеграция с Telegram)
* aiohttp (асинхронные HTTP‑запросы)
* Docker/Docker Compose (контейнеризация)


## Функциональные возможности


* Создание напоминаний с указанием времени отправки.
* Отправка уведомлений в Telegram‑чат.
* Обновление статуса напоминания после отправки.
* Асинхронная обработка задач через Celery.
* Изоляция сервисов в отдельных Docker‑контейнерах.

## Установка и запуск

### Требования

* Docker и Docker Compose
* Python 3.11+ (для локальной разработки)
* Telegram Bot Token (для отправки уведомлений)


### Локальный запуск через Docker Compose


1. Скопируйте репозиторий:
   ```bash
   git clone https://github.com/George-lab-star/Reminder
   cd Reminder
   ```

2. Создайте `.env`-файл в корне проекта:
   ```env
   POSTGRES_USER=reminder_user
   POSTGRES_PASSWORD=strong_password_123
   POSTGRES_DB=reminders_app

   DATABASE_URL=postgresql+asyncpg://${POSTGRES_USER}:${POSTGRES_PASSWORD}@db:5432/${POSTGRES_DB}

   BOT_TOKEN=ваш_telegram_bot_token
   ```

3. Запустите сервисы:
   ```bash
   docker-compose up -d --build
   ```

4. Проверьте статус:
   ```bash
   docker-compose ps
   ```

## Использование

### Создание напоминания

Зайдите в телеграм бот, токен которого Вы указали, и нажмите на кнопку старт. Бот зарегистрирует пользователя. Дальше впишите команду /remind <текст_без_пробелов> <минуты_через_которые_придёт_уведомление>
Через указанное время придёт уведомление с вашим текстом.
